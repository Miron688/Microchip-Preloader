# Microchip-Preloader - Проект "Страница предварительной загрузки"
## Описание проекта
Данный проект создан для анимрования загрузки в виде микрочипа. 
## Цели проекта
- Создание анимации загрузки в виде микрочипа
## Используемые технологии
- HTML cоздание структуры.
- CSS создание стилей, внешнего вида.
## Установка зависимостей
Загрузите на компьютер необходимые файлы. После установки вынесете файл и разархивируйте его.
## Пример запуска
Для запуска файла должен быть разархивираваный проект и запустите index.html.
Проект выполнен в образавательных целях на онлайн курсе "Github" школы "Лидер"
